# DSA Interview Preparation

A structured collection of important programming and Data Structures &
Algorithms problems solved in Python for coding interview preparation.

## 🎯 Objective

The purpose of this repository is to strengthen problem-solving skills
and build a strong foundation in Data Structures and Algorithms through
consistent practice.

The problems are organized topic-wise, starting from programming
fundamentals and gradually progressing to common DSA concepts and
interview-oriented problems.

## 📚 Topics Covered

- Number Problems
- Pattern Problems
- Arrays
- Strings
- Linked Lists
- Stack
- Dynamic Programming
- Trees
